# Voice

> Swipefile of cuts for inspiration when drafting blog posts. Read before starting a piece; pick the cut whose register fits what you're trying to write.
> 
> Each file in `samples/` is a raw excerpt with a short source line — that's it. No rules, no style guide.

## Adding a cut

Drop a markdown file in `samples/`. Top of the file: source line (publication, author, date if known) and one line describing the register. Then the raw text in a fenced code block so markdown stays unrendered.
